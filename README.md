# 拼豆图纸工坊

个人主体可上线的微信小程序：把图片生成可制作的拼豆图纸，提供色号、用豆统计、制作打卡、编辑精修和本地作品库。

## v1.0 功能

- 图片转拼豆图纸：支持 24x24、32x32、40x40、48x48、64x64。
- 色板匹配：内置通用 48 色和马卡龙 24 色。
- 颜色数量控制：可限制 8、12、16、24、32、48 色。
- 图纸编辑器：画笔、橡皮、取色、颜色替换、撤销、制作打卡。
- 用豆清单：统计每个色号的用量和总颗数。
- 作品库：本地保存最近 24 个作品。
- 图纸导出：生成带网格、色号图例和数量统计的 PNG 并保存到相册。

## 开发

```bash
npm install
npm run dev:mp-weixin
npm run build:mp-weixin
```

使用微信开发者工具打开 `dist/dev/mp-weixin`。
